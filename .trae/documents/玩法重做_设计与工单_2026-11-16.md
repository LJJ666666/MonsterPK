## 0. 结论先行

原「最小补丁」升级为**核心玩法重做**，四条改动：

1. **进化全面道具化（等级 + 道具双门槛）**：第一次进化需达等级 **且** 用对应属性「之石」；第二次进化（仅火/水/草/龙）需达更高等级 **且** 用「精华」。**不进化不妨碍升级**。
2. **学习装置改成"携带宠物的个体开关"**：队伍里那只宠物的详情页显示开关；第三关馆主打赢后**播剧情对话再发**（幂等）；商店下架。
3. **删除护符金币**：金钱不再翻倍，只由野怪/首领/挂机/副本产出。
4. **经验重定**：出战击杀者先拿一半；剩余减半由开了开关的宠物均摊；**没人开开关则击杀者全额、无衰减**。

**影响面**：内容表（+18 道具 / 22 条进化）、存档（+1 字段，升版 11→12）、后端结算、前端 UI、前后端测试——完整纵向改造。分 5 工单，各自可验收、可回滚。

## 3. 最终规则（定稿）

### 3.1 进化：等级 + 道具双门槛

```ts
// EvolutionCondition 扩展：item 分支增加等级门槛
| { type: "item"; itemId: ItemId; minLevel: number }
```

- **判定**：`use_item` 时，服务端检查 `target.monster.level >= minLevel`，不足报 `EVOLUTION_LEVEL_NOT_MET`（不扣石）。
- **不进化不妨碍升级**：`levelUp` 不再设置 `pendingEvolution`（道具化后不再有"等级到达自动进化"的待确认态）。
- **前端**：`usableTargets()` 过滤时同时校验等级，等级不足不显示"对 X 使用"按钮（服务端仍兜底校验）。

### 3.5 经验公式（定稿）

设本次基础经验 `E`（野怪 `10+lv*6`，地图首领 `×3`），出战击杀者 `active`，开了开关且存活的携带宠集合 `S`（`S ⊆ party`）：

```
若 |S| == 0:
    active 获得 E                       // 无人分摊 → 全额、无衰减
否则:
    active 获得 floor(E * 0.5)          // 击杀者固定一半
    分享池 = E - floor(E * 0.5)
    分享池 = floor(分享池 * 0.5)        // 再减半（另一半衰减丢弃）
    S 中每只（含 active，若它也开了） = floor(分享池 / |S|)
```

- 代入 E=100、5 只全开（含 active）：`active=50+5=55`，其余 4 只各 5，共 75（25 衰减）。
- 代入 E=100、无人开：`active=100`。
- F04 等级帽仍对每只领取者生效（超帽冻结）。
- Boss 战仍不发经验；PVP / 共斗 / 挂机仍不碰宠物经验。
