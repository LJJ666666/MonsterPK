   - 进化石：`backend/src/game/mutations.ts:162-177`（`use_item` 的 `evolution` 分支，按服务端内容表判定、扣石、替换个体、更新图鉴）
   - 护符金币：`backend/src/game/battle.ts:123-126`（`moneyGain = (50 + level*10) * (hasAmuletCoin ? 2 : 1)`）
   - 学习装置：`backend/src/game/battle.ts:124`、`:343-351`、`:371-379`（全队存活成员分享经验）
2. **真正剩下的可感知缺口是内容表，不是代码**：4 种进化石里只有 `stone_thunder` 有适配幻兽（`src/game/data.ts:539` 的 `spark_mouse`）。`condition: { type: "item" }` 全仓仅此一条。`stone_fire` / `stone_water` / `stone_leaf` 在 4 个商店照常售卖（¥2100），买了以后背包里不会出现「对 X 使用」按钮（`src/pages/Camp.tsx:453-455` 无目标直接 `return null`）—— 这就是「买了用不了」的真实现象，但原因是**没有适配物种**，不是没有使用代码。
3. **另两处产品语义未定义**：
   - `amulet_coin` / `exp_share` 是「持有即生效（数量 > 0）」的关键道具，但文案写「携带后」「开启后」（`data.ts:403-404`），且全仓**没有**装备位 / 开关入口与对应持久化字段。
   - `exp_share` 当前给**每只存活队员各发全额** `expGain`（`battle.ts:371-375` 对每只调用 `grant(party[i])` 传同一个值），即 N 人队总经验是 N 倍，不是分摊。这是数值口径，代码没有写错，但规则从没被拍板过。
4. **建议**：先订正过时台账（文档事实，不需要拍板），游戏内容按**方案 A（最小闭环）**推进；方案 A 里「配哪三只幻兽」「是否改文案」「经验是否改分摊」这三条仍需杰哥拍板。

## 2. 三个待决问题

### 2.1 三种进化石无适配物种（内容表缺口）

- 现象：坚石市 / 绿叶镇 / 涌泉市 / 烈阳镇都能买（`data.ts:866/883/899/916`），NPC 还有宣传语（`:870`、`:903`、`:919`），但 `Camp.tsx:383-404` 的 `usableTargets()` 按 `e.condition.type === "item" && e.condition.itemId === itemId` 过滤，三种石头过滤结果恒为空 → `:455` 不渲染使用按钮。
- 反证：`stone_thunder` 有 `spark_mouse → thunder_rat`（`data.ts:539`），后端 `mutations.ts:164-168` 会命中并进化；`e2e_p32_mutations.mjs:262-264` 还断言 `stone_fire` 被拒 `EVOLUTION_NOT_APPLICABLE` 且不扣石 —— 也就是说这个「不可用」当前是**被测试锁死的正确行为**。
- 影响：玩家花 ¥2100 买到无用道具，属于可感知的产品问题；不需要改代码，只需要给 3 种石头各配至少 1 只幻兽的 `type:"item"` 进化条件（含目标物种）。

### 2.2 关键道具「持有即生效」与文案冲突

- 当前规则：只要 `inventory.amulet_coin > 0` / `inventory.exp_share > 0` 就全账号生效，买第 2 个不叠加，也不能关闭。
- 文案说「携带后」「开启后」，但没有任何装备位 / 开关 UI，也没有持久化状态字段。
- 两条路：① 把文案改成「持有即生效」（最小、不动存档）；② 做装备位 + 开关（要新增持久化字段 → `SCHEMA_VERSION` 11→12 且同步 `backend/src/lib/saveValidator.ts:26` 的 `EXPECTED_SAVE_VERSION`，并补旧档处置口径）。**这属于产品语义，必须杰哥定。**

### 2.3 学习装置的经验口径

- 现状：`grant(party[i])` 对每只存活队员都传同一个 `expGain`，队伍 N 人 => 单场总经验 N×`expGain`；倒下成员不给；等级帽冻结优先（`battle.ts:365-370`）。
- 地图首领分支同逻辑（`battle.ts:343-351`），且金钱是 `(50+lv*10)*2*5`（护符金币先 ×2，再 ×5）。
- Boss 战不发经验/金钱（`battle.ts:321-326`）。
- 待拍板：全额复制 / 分摊 / 减半，以及是否对 PVP / 共斗 / 挂机生效。护符金币同理：是否叠加、是否对首领 / PVP / 挂机生效、¥10000 定价与 ×2 的回收周期、刷钱风控。

| 方案 | 改什么 | 工作量 | 产品影响 | 是否要拍板 |
