## 1. 产品概述
一款浏览器可玩的原创抓怪回合制RPG原型，聚焦“战斗 + 捕获 + 队伍管理”的核心循环，并支持离线存档导出。
- 目标用户：喜欢回合制、收集与养成的玩家；独立开发者/设计验证场景
- 产品价值：用最小成本验证抓捕概率、属性克制、技能策略与收集驱动是否成立

## 2. 核心功能

### 2.1 用户角色
不区分角色（单机离线体验）。

### 2.2 功能模块
1. **启动页**：新游戏、继续游戏、导入/导出存档、设置
2. **营地（主界面）**：队伍、背包、图鉴、训练场入口、成就/进度
3. **训练场（对战+捕获）**：遭遇、回合制战斗、捕获、战后结算、掉落

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---|---|---|
| 启动页 | 新游戏 | 创建新存档：玩家名、初始伙伴（三选一）、难度（普通/轻松） |
| 启动页 | 继续游戏 | 加载本地存档（localStorage）并进入营地 |
| 启动页 | 导入/导出存档 | 导出为JSON文件；导入JSON并校验版本/校验和，失败给出错误提示 |
| 启动页 | 设置 | 音量、战斗速度、色盲友好配色、键位提示 |
| 营地 | 队伍 | 6只队伍槽位；查看详情（等级、属性、技能、状态）；调整站位；放生/收藏 |
| 营地 | 背包 | 道具分类：捕获装置、回复、战斗增益；使用道具影响队伍/战斗 |
| 营地 | 图鉴 | 已见/已捕获列表；每只怪物：属性、技能、栖息地提示（原型阶段为文本） |
| 营地 | 训练场入口 | 选择遭遇主题（草地/洞窟/海岸）；进入对战 |
| 营地 | 进度 | 统计：捕获数、连胜、最高等级、稀有遭遇次数 |
| 训练场 | 遭遇生成 | 依据主题与玩家进度生成敌方怪物（含稀有/精英权重） |
| 训练场 | 回合制战斗 | 速度决定先后；行动：技能、道具、换位、逃跑；状态：灼伤/麻痹/睡眠（可配置） |
| 训练场 | 属性克制 | 2-3种基础属性（原型默认：火/水/草/无）；倍率：0.5x/1x/2x |
| 训练场 | 捕获系统 | 捕获率 = 基础率 × 血量因子 × 状态因子 × 装置因子；动画与摇晃反馈；失败继续战斗 |
| 训练场 | 战后结算 | 经验、升级、学习技能（2选1或替换）、掉落道具、加入图鉴 |

## 3. 核心流程
主流程：玩家从营地进入训练场遭遇敌怪 → 回合制战斗削弱与施加状态 → 使用捕获装置捕获 → 战后获得经验与掉落 → 返回营地管理队伍与背包 → 重复循环以完成收集。

```mermaid
  G -->| "失败" | F

  I --> C
  C --> J["导出存档"]
  J --> C
```

## 4. 用户界面设计
### 4.1 设计风格
- 视觉定位：90年代掌机RPG致敬，但全部原创图形与排版语言（不使用任何宝可梦/任天堂素材、字标或UI资源）
- 主色：深靛蓝（背景）+ 琥珀黄（高亮）+ 薄荷绿（成功/捕获）+ 珊瑚红（危险/失败）
- 按钮：像素边框 + 轻微立体阴影；聚焦态明显（键盘可用）
- 字体：标题使用具有复古游戏感的展示字体；正文使用可读性更强的无衬线字体
- 布局：桌面优先，中心舞台（战斗区域）+ 两侧信息栏；卡片式面板承载队伍/背包
- 动效：进入战斗的“擦屏”转场；捕获时摇晃与震动（可关闭减少动效）

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|---|---|---|
| 启动页 | 主菜单 | 大标题、三段式菜单卡、存档导入/导出弹窗、底部小字版本号 |
| 营地 | 信息总览 | 顶部导航（队伍/背包/图鉴/训练场/进度）；右侧快速统计；中央卡片内容区 |
| 营地 | 队伍面板 | 6槽队伍条；选中怪物详情卡；技能列表与替换弹窗 |
| 训练场 | 战斗舞台 | 敌我立绘占位（矢量/像素风）；血量条；状态徽记；回合日志 |
| 训练场 | 指令面板 | 4格指令：技能/道具/换位/逃跑；技能展开为4格；键盘热键提示 |
| 训练场 | 捕获反馈 | 摇晃次数、成功/失败提示、概率文案（可在设置中隐藏） |

### 4.3 响应式
- 桌面优先：≥1024px 显示双侧信息栏
- 平板/手机：信息栏折叠为抽屉；指令面板固定底部；触控按钮加大
